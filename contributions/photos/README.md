# Contribution photos

Do not commit binary photo files to this repository.

* In a proposal, put public photo/info links in the operation's `evidence`
  field (URL only, never a local path).
* The future https://data.metto.ir platform will host uploads externally and
  reference them from proposals the same way.
* If you must share a photo for a file-flow PR and have no host, attach it to
  the PR description — a maintainer will convert it to an `evidence` note or
  ask you to re-upload.
